# TaxShift

세법이 바뀌면, 근거가 확인된 문제로 바꿔 주는 수험생용 AI (금융인공지능 실무 수업 프로젝트)

- 만든 사람: 김채은 (한양대학교 경제금융학부 3학년)
- 상태: **시연(프로토타입) 수준**입니다. 서비스로 출시한 것이 아닙니다.

## 문제

세법은 매년 바뀌고, 수험생은 교재와 따로 개정 내용을 직접 따라가야 합니다. 2026년 세무사 1차 시험에서 세법학개론 과락률은 74.21%였습니다 (출처: 한국세정신문).

## 하는 일

1. **개정 감지**: 법제처 국가법령정보 Open API(신구법)로 최근 개정된 법령을 찾습니다.
2. **변경점 카드**: 어느 법 몇 조가 바뀌었는지, 바뀌기 전과 후를 쉬운 말로 한 장에 정리합니다. (AI 요약이므로 원문을 함께 봐야 합니다.)
3. **문제 생성**: 개정 조문으로 4지선다와 O/X 문제를 만들고, 정답마다 근거 문장을 붙입니다.
4. **3단계 검증**: (1) 근거 문장이 신조문에 실제로 있는가 (2) 신조문만 보고 다시 풀어도 같은 답인가 (3) 개정 내용을 직접 묻는 문제인가(AI 심사). 통과하지 못하면 폐기합니다.
5. **자동 연결**: Apps Script가 하루 한 번 개정을 감지하고, 새 개정이 있으면 2~4단계를 자동으로 실행해 결과(JSON)를 저장합니다. 풀이 화면은 그 주소에서 최신 결과를 불러옵니다.
6. **풀이 화면**: 결과를 불러와 풀고, 근거와 검증 기록을 보고, 오답노트와 개정 요약, 키워드 검색을 씁니다. 시험 기준일을 넣으면 그날 시행 중인 개정만 남깁니다(법 전체 시행일 단순 비교).

## 파일

| 파일 | 설명 |
| --- | --- |
| `taxshift_pipeline.py` | Google Colab 셀 하나로 실행하는 통합 코드 (감지 → 카드 → 문제 → 검증 → 결과 파일 `taxshift_run.json`) |
| `taxshift_watch.gs` | Google Apps Script. 매일 오전 8시 개정을 감지하고, 새 개정이 있으면 카드·문제 생성·검증까지 자동 실행해 결과를 저장·제공(웹 앱)하고 이메일로 알림 |
| `taxshift_quiz.html` | 풀이 화면. 브라우저에서 파일을 열면 되고, 로그인이 필요 없습니다. 열면 자동 수집 결과를 불러오고, 실패하면 샘플 문제를 보여 줍니다 |

## 실행 방법

### Colab
1. [Google Colab](https://colab.research.google.com)에서 새 노트북을 만들고, `taxshift_pipeline.py` 내용을 셀에 붙여넣고 실행합니다.
2. 입력창이 나오면 **법제처 OC 키**(open.law.go.kr 신청), **Anthropic API 키**를 직접 입력합니다. 코드에 키를 적어 두지 않았습니다.
3. 끝나면 `taxshift_run.json`이 만들어집니다.

### 풀이 화면
1. `taxshift_quiz.html`을 브라우저로 엽니다. 샘플 문제 12개가 들어 있습니다.
2. 위의 "내 Colab 결과 불러오기"에서 `taxshift_run.json`을 고르면 내 결과로 바뀝니다. 파일은 브라우저 안에서만 읽습니다.

### 자동 흐름 (Apps Script)
1. [script.google.com](https://script.google.com)에서 새 프로젝트를 만들고 `taxshift_watch.gs`를 붙여넣습니다.
2. 프로젝트 설정 > **스크립트 속성**에 `OC`(법제처 키), `API_KEY`(Anthropic 키), `MAIL_TO`(받을 이메일)를 직접 입력합니다. 코드에는 키가 없습니다.
3. `seedAll`을 실행해 4개 법령의 최신 개정으로 첫 결과를 만듭니다(시간이 모자라면 "실행 완료"가 나올 때까지 다시 실행).
4. 배포 > 새 배포 > 웹 앱(실행 계정 나, 액세스 모든 사용자)으로 배포하고, 나온 `/exec` 주소를 `taxshift_quiz.html`의 `AUTO_URL`에 넣습니다.
5. `installTrigger`를 한 번 실행하면 매일 오전 8시에 감지 → 카드·문제 생성 → 검증 → 저장이 자동으로 돌아갑니다.
- 키는 **본인 Apps Script 속성에만** 입력하고 GitHub에는 올리지 마세요.

## 직접 확인한 것

- 2026-11-02 기준 최근 60일 안에 공포된 **국세기본법 개정**(2026-09-29 공포, 2026-10-02 시행)을 감지하고, 카드와 문제를 만들어 검증한 뒤 이메일로 보냈습니다 (수동 실행).
- 오류를 찾아 고쳤습니다: AI가 쓴 조문 번호 오류, 표시 태그 때문에 생긴 비교 오류, 한자 코드 차이로 멀쩡한 문제가 폐기되는 오류.
- 고친 뒤 실행에서 4지선다는 세 번 모두 폐기 없이 통과(10개·7개·7개), O/X는 7개 중 6개 통과했습니다. **표본이 작은 단일 실행이며 일반화할 수 없습니다.**

## 한계

- 자동 실행은 하루 한 번이며, 새 개정이 감지될 때만 카드·문제를 만듭니다. 실행 시간 제한 때문에 법령당 2개 묶음만 만듭니다(Colab은 3개). Colab 통합 코드는 수동 실행용으로 남겨 두었습니다.
- 자동 생성도 AI 호출이 간혹 형식 오류로 실패해 '오류'로 기록될 수 있습니다. 풀이 화면은 통과한 문제만 보여 주고 나머지는 '통과하지 못한 항목'에 표시합니다.
- 자동 흐름은 11월 27일 실행에서 4개 법령의 최신 개정 5개 묶음을 처리한 것까지 직접 확인했습니다. 실제로 **새 개정이 생겨 자동으로 감지된 경우**는 아직 겪어 보지 못했고, 법인세법 기록을 되돌린 시연(`demoRollback`)으로만 시험할 수 있습니다.
- 검증 통과는 **법적 해석이 맞다는 뜻이 아닙니다.** 현직 전문가 검수는 계획이며 아직 하지 않았습니다.
- 시험일 필터는 법 전체의 시행일만 비교합니다. 조문마다 시행일이 다른 부분 시행은 구분하지 못합니다.
- 풀이 화면에는 로그인, 영구 저장, 화면 안에서 새 문제 만들기가 없습니다.
- 개정 유형 표시는 규칙으로 분류한 참고용이라 틀릴 수 있습니다.
- 메일 시연 중 법인세법 개정 감지는 저장된 기록을 과거로 되돌려 만든 시연입니다.
- 법령 본문은 저작권법 제7조상 보호 대상이 아니지만, 법제처 API 이용 조건을 따라야 합니다.
